#+title: Registry

* Introduction
Just to simplify the architecture, a private registry is built on /FreeBSD/ inside a jail without any security stack.

* Process

** Permission
First of all, we have to enable access on the insecure registry
#+begin_src yaml
{
  "builder": {
    "gc": {
      "defaultKeepStorage": "20GB",
      "enabled": true
    }
  },
  "experimental": false,
  "insecure-registries": [
    "192.188.200.67:5000"
  ]
}
#+end_src
We don't forget to restart our docker desktop
** tag and push
We add a new tag on the images and finally push the images on the registry.
#+begin_src shell
for image in cl-backend cl-frontend cl-oracle cl-proxy; do
  docker tag \
    "gandalfthewhite/${image}:latest" \
    "192.188.200.67:5000/gandalfthewhite/${image}:latest"

  docker push \
    "192.188.200.67:5000/gandalfthewhite/${image}:latest"
done
#+end_src

** Kubernetes
To reference this new private registry, we just have to write this part
#+begin_src yaml
containers:
  - name: backend
    image: 192.188.200.67:5000/gandalfthewhite/cl-backend:latest
#+end_src
